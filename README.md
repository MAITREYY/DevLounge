# 🚀 DevSuite Pro — Fluid Developer Utility Suite v2.0

> **Modern Web Developer Toolbox & Precision Fluid UI Generators**

DevSuite Pro (FluidTools Suite v2.0) is a modern, ultra-fast web application built with **Vite**, **React 18**, **Tailwind CSS**, and **Framer Motion**. It provides zero-dependency CSS generators and layout calculators to create responsive typography, container artboards, glassmorphism surfaces, CSS grids, and ambient box shadows in seconds.

---

## ✨ Features & Included Utilities

### 🔤 1. FluidClamp — Fluid Typography Generator
- **CSS `clamp()` Calculation**: Mathematical font size scaling across mobile & desktop viewports without media queries.
- **Interactive SVG Curve Graph**: Real-time slope graph visualization.
- **Live Viewport Simulator**: Interactive screen slider with real-time text scaling preview.
- **WCAG 2.1 Contrast Auditor**: Built-in color contrast inspector with AA/AAA pass scores.
- **Typography Scale Presets**: Quick scale presets for Body, Subheading, Header, and Hero display titles.

### 📦 2. FluidBox — Figma Container & Artboard Studio
- **Figma Presets**: 1-click select for iPhone 15 Pro, iPad Pro, MacBook Pro 14", and 4K Desktop artboards.
- **Padding Control**: Independent side and vertical padding sliders.
- **Container Query Generator**: Export CSS standard rules, Tailwind `max-w-*` classes, and `@container` queries.

### ✨ 3. Glassmorphism Architect — Frosted Glass Studio
- **Backdrop Blur & Opacity Sliders**: Real-time glass transparency and blur radius tuning.
- **Border Sheen & Noise**: Subtle glass reflection controls with live preview card.

### 📐 4. CSS Grid Architect — Visual Layout Builder
- **Dynamic Columns & Gap Controls**: Configure 1 to 12 responsive grid columns.
- **Live Grid Canvas**: Renders updating layout boxes in real time.

### ☀️ 5. Box Shadow Studio — Ambient Elevation & Glow Studio
- **Multi-Layered Elevation**: Configure Y-offset, blur radius, spread, and shadow color.
- **Neon Glow Generator**: Create colorful glowing element accents.

## 💻 Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite 5](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: [Canvas Confetti](https://github.com/catdad/canvas-confetti)

## 🛠️ Local Development & Setup

```bash
# 1. Clone the repository
git clone https://github.com/MAITREYY/DevSuite-Pro.git

# 2. Navigate to project directory
cd DevSuite-Pro

# 3. Install dependencies
npm install

# 4. Start local dev server
npm run dev
```

Open `http://localhost:3000` in your browser.
