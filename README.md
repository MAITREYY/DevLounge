# 🚀 DevLounge — Developer Utility Suite v2.0

> **Modern Web Developer Toolbox & Precision Fluid UI Generators**

DevLounge is a modern, ultra-fast web application built with **Vite**, **React 18**, **Tailwind CSS**, and **Framer Motion**. It provides zero-dependency CSS generators and layout calculators to create responsive typography, container artboards, image conversions, glassmorphism surfaces, CSS grids, and ambient box shadows in seconds.

---

## ✨ Features & Included Utilities

### ⚡ 1. Tailwind Extractor
- **Class Extraction**: Scan 20+ WordPress PHP, HTML, or React JS files, extract unique utility classes, and compile a minified production CSS bundle instantly.

### 🛡️ 2. Code Vault
- **FTP Backup & Version Control**: Backup PHP, CSS & JS code before editing WordPress theme files over FTP with side-by-side code diffs and 1-click restore.

### 🎬 3. Video Converter
- **Browser-Native Video Processing**: Convert MP4, WebM, MOV & AVI videos to WebM, MP4 or Animated GIF with custom bitrates, resolution scaling, audio stripping, and clip trimming.

### 🖼️ 4. Image Converter
- **Format Converter & Compressor**: Convert PNG, JPEG, WebP, AVIF & BMP images locally with live quality tuning, dimensional scaling, and side-by-side comparison.

### 🔤 5. Fluid Clamp
- **Fluid Typography Generator**: Calculate CSS `clamp()` font scaling across mobile & desktop viewports without media queries, featuring SVG curve graph & contrast audit.

### 📦 6. Fluid Box
- **Figma Container Studio**: Generate layout containers for Mobile and PC Figma artboards with controlled side and vertical padding.

## 💻 Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite 5](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: [Canvas Confetti](https://github.com/catdad/canvas-confetti)

## 🛠️ Local Development & Setup

```bash
# 1. Clone the repository
git clone https://github.com/MAITREYY/DevSuite-Pro.git

# 2. Navigate to project directory
cd DevSuite-Pro

# 3. Install dependencies
npm install

# 4. Start local dev server
npm run dev
```

Open `http://localhost:3000` in your browser.
